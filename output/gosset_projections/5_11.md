# 8-orthoplex (5_11) - interactive 3D viewer (page 1)

**[Open this page on GitHub Pages](https://nanma80.github.io/zomeable-4polytopes/output/gosset_projections/5_11.html)** to interact with these models.

[Back to Gosset projections index](VIEWER.md).

Strict orthographic zomeable projections of the 8-orthoplex (`5_11`).

**Note.** These 18 models are the completed R=3-confirmed set; the R=3 sweep matched the R=2 set exactly.

In the captions, "balls" means distinct 3D ball positions in the vZome model after projection.
