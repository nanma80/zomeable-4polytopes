# Approximate Platonic and Archimedean zomes — interactive gallery

**[Open this page on GitHub Pages](https://nanma80.github.io/zomeable-4polytopes/output/approximate_zomes/VIEWER.html)** to interact with the 11 curated models below.

These are approximate RGBY zome models of 3D Platonic and Archimedean-solid
graphs. They are not part of the strict 4-polytope orthographic projection
classification.

For context and generation notes, see
[`docs/APPROXIMATE_ZOMES.md`](../../docs/APPROXIMATE_ZOMES.md).
That page also includes references and acknowledgements for related earlier
Zometool approximation constructions.
